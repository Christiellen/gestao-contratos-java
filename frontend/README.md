# Front-end (Angular 19)

SPA da Gestão de Contratos. Veja o [README principal](../README.md) para a visão geral.

```bash
npm ci
npm start          # http://localhost:4200, com proxy de /api para http://localhost:8000
npm run test:ci    # testes unitários (Karma + Chrome headless)
npx ng build       # build de produção em dist/frontend/browser
```
